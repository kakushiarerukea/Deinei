#  Deinei（泥濘）

**LLM推論 × 長期記憶RAG × Live2D連動UI × リアルタイムTTS音声合成** を統合した、完全ローカルAI対話ソフトウェアです。

有限なコンテキストウィンドウ（16,384トークン）内で、**「無限に近い長期対話」「KVキャッシュヒット率の向上」「Live2Dの感情表現・口パク同期」** の実現を、8~24GBのVRAMで完全ローカルで達成することが、本リポジトリの目標です。

---

## 主な特徴 (Features)

-  **記憶システム**:
  - **16ブロック忘却スライディング**:
    - 30メッセージ蓄積ごとに直前ログを約300〜500トークンの要約ブロックへ圧縮（直近10件は文脈維持のため生ログとして保持）。
    - 最大16ブロック（約4,000トークン）を上限に保持し、超過時は最古の2ブロックを押し出すことで、16,384トークンの枠内でコンテキスト溢れを防ぎ循環。
    - 押し出された要約ブロックは破棄されず、親子リトリーバル（ChromaDB）へ自動アーカイブ。
  - **親子リトリーバル (Parent-Child RAG)**:
    - 要約生成時に抽出された重要キーワード群を検索用インデックス（子）、要約ブロック全文（最大500文字）を親データとしてChromaDBに二層保持。
    - 日本語埋め込みモデル `cl-nagoya/ruri-v3-310m` を採用し、Fact記憶とEpisode記憶を独立検索（Dual-Query）。コサイン類似度0.85以上の厳格な閾値でノイズを遮断。
    - 関連する話題が出た際、過去エピソード全文（最大2件・計800文字上限）をユーザー発言直前へ動的注入し、KVキャッシュを保護しながら過去体験を想起。
  - **相対時間プロキシ**:
    - DB内には不変のISOタイムスタンプで保持し、推論時にプロキシ（`server.py`）側で現在時刻との差分秒数を動的計算。
    - `[たった今]`, `[15分前]`, `[3日前]`, `[2ヶ月前]` などの主観的な時間タグへ変換してRAG記憶へ付与し、LLMの時間認識ズレを防止。
    - 動的日時情報はコンテキスト最後尾（ユーザー発言直前）へ局所注入することで、過去ログのKVキャッシュ（Prefix Caching）を破壊せず即時応答を維持。
  - **世界線分離 (Worldline Isolation)**:
    - **有向木分岐とスナップショット復元**: 会話履歴を有向木（Tree）構造としてIndexedDBに保持。再生成や過去発言の編集による分岐時、メッセージノード単位で不変保持された要約スナップショット（`aiHistoryTextListSnapshot`）により、分岐当時の文脈・要約ブロック状態へ即時ロールバック。
    - **アクティブパスによる記憶遮断（ChromaDB）**: 長期記憶リトリーバル時、ルートから現在ノードまでの祖先ノードID群（`active_message_ids`）を推論プロキシへ伝達。他ブランチ（別世界線）で生じた事実・エピソード記憶を完全除外・遮断し、共通祖先の記憶のみを想起。
    - **要約・再構築時の一本化（Consolidation / Linearization）**: 30メッセージごとの要約圧縮時、過去の試行錯誤や分岐の枝葉を排し、現在のアクティブパスのみを1本の客観的あらすじ（要約ブロック）へ不可逆的に統合。また会話インポートや記憶再構成（Rebuild Memory）時も、選択されたアクティブパスを線形化してクリーンな一筋の履歴として再インデックス。
-  **Live2D ＆ 音声同期 (Avatar & TTS)**:
  - **PixiJS + Live2D Cubism アバター描画**:
    - WebGLによる高効率描画と、画面比率に応じた上半身クローズアップ（約1.3〜2.1倍）の自動スケール計算。
    - 2モデル対応（銀髪モデル: 5衣装切り替え・12表情動的補完 / 茶髪モデル: ファジーマッピング）。自律まばたき（120ms補間）および顔中心基準（-1.0〜1.0）の視線・頭部マウス追従を搭載。
  - **GUIおさわり判定エディター (TouchZones)**:
    - ポインター累積移動量による「撫でる（Pat）」判定と部位クリック判定を分離し、表情変化および非表示プロンプトの自動送信（5秒クールダウン）をトリガー。
    - 画面上の当たり判定矩形をドラッグ＆リサイズ可能なGUIエディターを備え、部位・文言・表情設定をモデル別に永続化。
  - **Irodori-TTS 音声合成 ＆ セリフ抽出**:
    - 量子化モデル（INT8/FP8）× `Semantic-DACVAE`（24kHz）による完全ローカル音声合成。起動時のリファレンス自動生成（VoiceDesign・声ガチャ）と常駐ゼロショット生成（VoiceClone）でVRAMを節約。
    - `<think>` 思考タグ、Markdown、ト書き（動作描写）を正規表現で完全ストリップし、セリフのみを約100文字チャンク＋0.15秒ポーズで自然に合成。
  - **先読みパイプライン ＆ 口パク・感情タイムライン同期**:
    - Web Audio API（FFT 256）のノイズゲート・指数平滑化フィルターによる滑らかな口開閉（`ParamMouthOpenY`）連動。
    - 発話文節の再生中に後続セリフをバックグラウンド先行生成する先読みキャッシュにより、文節間の待ち時間0秒を実現。テキスト内の感情語出現位置と音声再生進捗（ratio）を同期させ、発話中にリアルタイムで表情を自動遷移。
  - **【超試験的オマケ】ReazonSpeech-K2 音声認識 ＆ 自動対話 (STT)**:
    - 日本語音声認識モデル `ReazonSpeech-K2` をローカル統合。VRAMを消費しないよう完全CPU推論かつ遅延ロード（初回音声入力時にオンデマンド展開）を採用しています。
    - ブラウザ録音からの自動文字起こし・自動送信（ハンズフリー対話）に対応していますが、**現状は突貫工事で追加しただけの超試験的なオマケ機能**です。全体の整備が全く追いついておらず、対話テンポや誤認識への対処など使用感はお世辞にも良いとは言えません（今後しっかり調整・改善していく予定ですので、現時点では「動いたらラッキー」程度のオマケとして今後にご期待ください）。
-  **Web UI (llama.cpp WebUIベース / Svelte 5 & Tailwind CSS)**:
  - **公式WebUIの非侵襲的拡張 ＆ 言語分け設計**:
    - `llama.cpp` 公式（`tools/ui`）の堅牢なSvelte 5チャット基盤を最大限そのまま維持し、API通信先（`api-endpoints.ts`）をローカル中継プロキシ（`server.py` :5000）へ向ける最小限の透過的フックでRAG・要約・Live2Dを2ペイン統合。
    - 日常的な対話・UI・記憶設定は完全日本語対応（日英切替対応）。一方でllama.cpp本来の高度なサンプリング・ペナルティ設定（Temperature, Top-P, Mirostat等）は公式準拠の英語表記をそのまま保持する二層構造。
  - **初期設定ウィザード (DialogInitialSetup)**:
    - 初回起動時に自動立ち上げ。言語選択、Irodori-TTS自動読み上げ、字幕風の音声・文章同期表示、Web検索・気象取得（キーワード発言時のみ動的トリガー）、恋人ロールプレイ推奨システムプロンプト（上書き防止ダイアログ付き）、Reasoning自動OFFをワンストップで設定可能。
  - **リアルタイム・コンテキスト内訳ゲージバー（7色スタック表示）**:
    - CJK文字（1文字≒0.75t）と英数字を分離して高精度トークン推定を行い、llama.cppの実測コンテキスト消費量（`actualContextUsed`）へプロポーショナル（比率）スケールで完全一致補正。
    - 16,384トークンの枠内を「システム設定（紫）」「要約ブロック（青）」「RAG記憶・Web検索（緑）」「直近対話（橙）」「Reasoning思考文（桃）」「ツール・MCP（水）」「空き容量」の7色でスタック可視化（ホバーでトークン数・文字数・占有率を表示）。
  - **ロールプレイ特化演出 ＆ 相対OKLCH色相環スキン**:
    - 独自Rehypeプラグインにより、Gemma等で出力されがちな「」カギ括弧の自動消去や、`*情景描写（ト書き）*` の自動斜体・薄色スタイリング、タイプライター順次表示を実装。
    - CSS変数 `--theme-hue`（0°〜360°）を起点に、OKLCH色空間上で明度・彩度・色相オフセットを相対計算。色相環スライダーひとつで、ライト/ダーク双方の視認性を数学的に保証したままUI全体が瞬時に連動変色。
  - **サイドバー拡張管理パネル群 (RAG / Debug / TTS)**:
    - ChromaDB記憶（Fact/Episode）のリアルタイム閲覧・手動編集・削除パネル、想起記憶インスペクター、次回要約までのカウントダウン、手動強制要約、記憶完全再構成（Rebuild Memory）、要約プロンプト・温度パラメータの動的エディターを外付け増設。
-  **スマートWeb検索 ＆ リアルタイム気象予報 (Web Search & Weather API)**:
  - **2段階自律検索パイプライン (2-Stage Pipeline)**:
    - **Stage 1 (ローカルLLM判定)**: 思考プロセスをOFF（`enable_thinking: False`）にした超低遅延パス（約0.1秒）により、直近会話文脈や添付画像（マルチモーダルmmproj）から検索要否を自律判定。「この本」「その人」などの指示語を会話や画像内の書名・著者名等から具体的な固有名詞へ自動解決し、最適な検索クエリを生成（日常会話やスキンシップでは外部通信を遮断）。
    - **Stage 2 (外部取得＆キャッシュ)**: 時事・速報・政治などのクエリはDuckDuckGo News検索（最大3件）、一般情報はText検索を優先実行。取得データは1時間インメモリキャッシュ（`_SEARCH_CACHE`）に保持され、同一トピックでの重複通信を防止。
  - **Open-Meteo ＆ Nominatim によるリアルタイム気象連携**:
    - 完全無料・APIキー不要の気象パイプラインを統合。発言内の地名からNominatim（OpenStreetMap）で緯度・経度を逆引きし、Open-Meteo APIから「今日・明日・明後日」のWMO気象コード（快晴・雨・雪等）、最高/最低気温、降水確率を取得。
    - 取得した気象データはプロンプトへ注入され、システムプロンプトの情景描写ルール（`* *`）と連動。「外、雨が強くなってきたね」「明日は冷え込むみたい」といった現実に即したロールプレイを成立。
  - **ワンクリックトグル ＆ KVキャッシュ完全保護**:
    - チャット入力欄直下の専用トグル（`ChatFormActionSearchToggle`）により、ワンクリックで瞬時に機能の有効/無効を切り替え可能。
    - 検索結果はコンテキスト末尾（ユーザー発言直前）へ局所注入されるため、OFF時は外部通信が一切発生せず、過去ログのKVキャッシュ（Prefix Caching）を100%保全して最速の推論速度を維持。
  > [!WARNING]
  > **【プライバシーとネットワーク通信に関する最重要警告】**
  > 本ソフトウェアは、LLM推論・長期記憶ベクトルDB（ChromaDB）・Live2D描画・TTS音声合成のすべてがPCローカル内で完結する**完全オフライン設計**を原則としています。
  > しかし、**本機能（Web検索・気象予報）をONにしている場合に限り、外部インターネットへの接続が発生します**。具体的には、ユーザーの発言や画像から抽出・生成された検索キーワードおよび地名情報が、外部サーバー（DuckDuckGo、OpenStreetMap、Open-Meteo）へHTTPリクエストとして送信されます。
  > 個人情報・機密情報を含む対話を行う場合や、外部へのデータ送信を一切遮断したい完全隔離環境では、**必ず本トグルをOFFにしてご利用ください**（トグルOFF時は天気APIを含むすべての外部通信が完全に遮断されます。初期設定ウィザードおよびチャット画面からワンクリックで常時無効化可能です）。

### 1. 自動インストーラーによる導入手順（Windows推奨）

> [!CAUTION]
> **【最重要】必ずダウンロードしたZIPファイルを「解凍（すべて展開）」してから実行してください！**
> ダウンロードしたZIPファイルをダブルクリックして中身を開いただけの状態で `install.bat` を実行すると、Windowsの一時フォルダ（Temp）で動いてしまい、**必要なファイルが見つからずエラーで強制終了します**。
> 必ず以下の手順に従って、通常のフォルダへ展開してから作業を開始してください。

#### ステップ 1: ダウンロードとZIPの解凍（展開）
1. 本リポジトリのZIPファイルをダウンロードします。
2. ダウンロードフォルダ内のZIPファイルを **右クリック →「すべて展開...」** を選択します。
3. 展開先フォルダを指定して「展開」をクリックします。
   - 💡 **フォルダ配置のポイント**:
     - **十分な空き容量**: モデルのダウンロードや環境構築のため、**35GB以上の空きがあるSSDドライブ** を推奨します。
     - **半角英数字のパス推奨**: フォルダの場所や名前に日本語（全角文字）やスペース、極端に深い階層が含まれていると、Pythonやツールの誤作動の原因になる場合があります。`C:\deinei` や `D:\deinei` など、半角英数字の分かりやすい場所への展開を強く推奨します。
     - ※ OneDrive等のクラウド同期下にあるフォルダ（デスクトップやマイドキュメント直下）は、ファイルロックや同期競合によるトラブルが発生しやすいため避けてください。

#### ステップ 2: 自動セットアップの実行
1. 解凍して展開されたフォルダを開き、直下にある **`install.bat`** をダブルクリックして実行します。
   - ⚠️ **青い警告画面（SmartScreen）が出た場合**:
     - 「WindowsによってPCが保護されました」と表示された場合は、**「詳細情報」をクリックし、現れた「実行」ボタン** を押してください。
2. **黒い画面（コマンドプロンプト）** が立ち上がり、以下のセットアップが全自動で進行します。途中で閉じずにそのままお待ちください（回線速度により数分〜十数分）。
   - ハードウェア（GPU / VRAM）自動診断 ＆ 最適プロファイル生成
   - Python 3.10 仮想環境（`.venv`）の自動構築（`uv` による高速自動取得）
   - PyTorch (CUDA 12.8 / 12.6) ＆ 音声/対話用ライブラリの自動インストール
   - `llama.cpp` 最新バイナリ ＆ NVIDIA CUDA 13.3 ランタイムの自動取得
   - `Irodori-TTS` 音声合成モデルの自動取得
   - Svelte 5 WebUI のセットアップ
   - 起動用ランチャー（`start_ai_servers.bat`）の生成
3. 処理の終盤で、画面に **「モデル一式 (約16GB) を今すぐ自動ダウンロードしますか？ (y/n)」** と表示されます。
   - キーボードの **`y`** を押して Enter を入力してください。
   - 推奨対話モデル本体（`Melody1437-27B.i1-IQ4_XS.gguf` 約15.2GB）およびマルチモーダル画像認識用エンコーダ（`mmproj-BF16.gguf` 約885MB）が自動ダウンロードされます（※後から手動で配置したい場合は `n` でスキップ可能です）。
4. 画面に **`[SUCCESS] Setup Completed!`** と表示されたら導入完了です。Enterキー等を押して画面を閉じてください。デスクトップに **「泥濘 (Deinei) を起動」** のショートカットが自動作成されます。

---

### 2. 🖥️ 起動方法

1. デスクトップに作成された **「泥濘 (Deinei) を起動」** ショートカット（またはフォルダ直下の **`start_ai_servers.bat`**）をダブルクリックします。
2. AIサーバーを裏で動かすための **黒い画面（コマンドプロンプトのウィンドウ）** がいくつか立ち上がります。
   - 💡 **大切な注意**: この黒い画面はAIを動かしている本体です。**対話中は閉じずにそのまま最小化** しておいてください（途中で閉じるとAIが停止してしまいます）。
3. 全サーバーの準備が整うと、**自動的にブラウザで対話画面（Web UI）が開きます**。
4. 初回起動時は「初期設定ウィザード」が表示されますので、画面の案内に沿ってお好みの設定を行ってください。

> [!TIP]
> **システムの終了方法**:
> 使い終わったら、開いているブラウザを閉じたあと、**立ち上がっている黒い画面（コマンドプロンプト）の右上の「×」ボタンを押してすべて閉じる** だけで安全に一括終了できます。
