# アバター（Live2D / VRM 3D）・音声合成・音声認識仕様書 (Avatar & Audio)

本書は、泥濘 (Deinei) システムにおける Live2D Cubism および VRM 3D アバター描画、GUIおさわり判定エディター（TouchZones）、Irodori-TTS によるローカル音声合成、先読み口パク・感情同期、および音声認識（STT）に関する技術仕様を定義したドキュメントです。

---

## 1. 概要

泥濘は、LLMのテキスト応答にあわせて 2D（Live2D）または 3D（VRM）キャラクターの表情・視線・口パクを滑らかに同期させ、ローカル音声合成（Irodori-TTS）による自然な読み上げを提供します。また、マウスポインターによるインタラクション（撫でる・クリック）に対応したGUIエディターを内包しています。

## 2. Live2D アバター描画仕様

### 2.1 レンダリングエンジンと自動スケール
- **描画技術**: WebGL 上で動作する PixiJS 7.x および `pixi-live2d-display` を採用しています。
- **自動スケール計算**: 画面アスペクト比に応じたフィットスケールを基準に、上半身クローズアップとして2.1倍ズームを適用し、さらにモデル特性に応じた個別補正（銀髪×1.3倍／茶髪×1.18倍、実効約2.48〜2.73倍）を自動計算して、会話に適した構図を維持します。
- **対応モデル形式**: Live2D Cubism 3 / 4 形式（`.model3.json`、Cubism 4 Core SDK採用）に対応しています。

### 2.2 プリセットモデルと自律動作
- **銀髪モデル**: 5種の衣装切り替え、12種の表情動的補完に対応。
- **茶髪モデル**: ファジーマッピングによる表情切り替えに対応。
- **自律まばたき**: 120ms補間による自然な周期まばたきを実装。
- **マウス追従**: 顔の中心を基準（-1.0〜1.0）とした滑らかな視線・頭部ポインター追従処理を搭載。

## 3. VRM 3D アバター描画仕様

### 3.1 レンダリングフレームワークとライセンス
VRM 3D アバターの描画・制御には、オープンソースの標準フレームワークを採用しています。

- **three.js**:
  - WebGL 3D レンダリングパイプライン、シーングラフ、ライティング、カメラ制御を担当。
  - ライセンス: MIT License (Copyright (c) 2010-2025 three.js authors)
  - 公式リポジトリ: [mrdoob/three.js](https://github.com/mrdoob/three.js)
- **@pixiv/three-vrm**:
  - VRM 0.x および VRM 1.0 仕様準拠のヒューマノイドボーン制御、表情ブレンドシェイプ（Expression）、SpringBone 物理演算、視線追従制御（LookAt）を担当。
  - ライセンス: MIT License (Copyright (c) 2019-2026 pixiv Inc.)
  - 公式リポジトリ: [pixiv/three-vrm](https://github.com/pixiv/three-vrm)
- **VRM 規格**:
  - glTF 2.0 をベースとした 3D アバター向けのオープン標準仕様。
  - 仕様策定: 一般社団法人 VRM コンソーシアム ([vrm.dev](https://vrm.dev/))

### 3.2 視線追従と待機モーション
- **視線追従**:
  - 視線は主に head ボーンの回転（yaw: 最大約20度、pitch: 最大約10度）を中心に追従します。
  - 目ボーンの稼働範囲はモデル制作者が定義した rangeMap の上限値（約1.3度〜3.6度程度、モデル依存）に連動します。
  - 視線の上下符号（gaze pitch sign）はロード時にモデルボーンの向きを計測して判定します。
- **手続き的待機モーション**:
  - 外部のモーションファイル（`.vrma`）に依存せず、脱力ポーズ、指のリラックスカーブ、呼吸周期運動を手続き的に生成して適用します。

### 3.3 モデル内包メタデータとライセンス尊重
- ユーザーがインポートした VRM モデルは、`backend/data/vrm_meta.py` により glTF JSON チャンク内の著作者情報、ライセンスURL/ライセンス名、ファイルサイズ、表情プリセット名等が抽出され、UI のモデル情報として管理されます（※アバター人格権等の詳細規約フラグ表示は将来拡張予定）。

## 4. GUIおさわり判定エディター (TouchZones)

### 4.1 判定ロジック
- **「撫でる (Pat)」と「クリック」の分離**:
  - ポインターの累積移動量を監視し、一定値以上のストロークを「撫でる」、単発押下を「クリック」として分離判定します。
- **クールダウンと自動送信**:
  - 各インタラクションには誤連打を防ぐ5秒のクールダウンを設けています。
  - トリガー成立時、指定された表情への即時切り替え、およびバックグラウンドプロンプト（ユーザーには見えない指示文）の自動送信を実行します。

### 4.2 ビジュアルエディター
- ブラウザ画面上に当たり判定矩形（頭部・左腕・右腕を既定とし、ユーザーによる追加・編集可能）を半透明オーバーレイで表示します。
- マウスドラッグで位置移動、右下ハンドルでサイズ変更（リサイズ）が可能。
- 各ゾーンごとの文言、送信プロンプト、適用表情はモデル単位でローカル永続化されます。

## 5. Irodori-TTS 音声合成 ＆ 先読みパイプライン

### 5.1 音声合成エンジン
- **モデル構造**: ハードウェアに応じたローカル音声合成モデル（24GB環境: BF16非量子化 / 16GB以下環境: float8量子化）と `Semantic-DACVAE`（24kHz）を採用しています。
- **VRAM節約設計**:
  - 起動時のリファレンス自動生成（VoiceDesign・声ガチャ）
  - 常駐ゼロショット音声合成（VoiceClone）
- **セリフ抽出と前処理**:
  - `<think>` 思考タグ、Markdown記法、情景描写（ト書き・`*動作*`）を正規表現で自動ストリップ（除去）し、発話セリフのみを抽出します。
  - セリフを約100文字前後のチャンクに分割し、0.15秒の適切なポーズ（間）を挟んで自然に合成します。

### 5.2 先読みパイプライン
- **先行生成キャッシュ**:
  - 最初の文節を再生している間に、後続のセリフチャンクを非同期パイプライン（Promise）で先行生成・キャッシュします。
  - キャッシュがヒットした場合、文節間の発話待機時間を最小限に抑制します。

### 5.3 口パク ＆ 感情タイムライン同期
- **Web Audio API による口パク連動**:
  - 音声再生ストリームを Web Audio API（FFT 256）でリアルタイム解析します。
  - ノイズゲート処理および指数平滑化フィルターにより、不快な小刻み振動を抑えた滑らかな口開閉（`ParamMouthOpenY`）を実現します。
- **感情同期タイムライン**:
  - 発話テキスト内の感情語の出現位置と、音声再生の進捗率（ratio）を同期させます。
  - セリフの途中でニュアンスが変わった場合でも、音声に合わせてリアルタイムにアバターの表情が遷移します。

## 6. 音声認識 (STT: ReazonSpeech-K2) ※試験的機能

- **エンジン**: 日本語音声認識モデル `ReazonSpeech-K2` をローカル統合。
- **リソース配慮**: VRAMを消費しないようCPU推論を採用し、初回音声入力時に Hugging Face より自動ダウンロードしてオンデマンドでモデルを展開（遅延ロード）します。
- **現状のステータス**:
  - ブラウザマイク録音からの自動文字起こしおよび自動送信（ハンズフリー対話）に対応していますが、現時点では試験的な提供にとどまります。
  - 環境ノイズやマイク入力レベル、生活音による誤認識や誤送信の可能性があるため、必要に応じて調整・利用してください。

## 7. モデルの準備・配置手順

### 7.1 Live2D モデルの配置
- **推奨配置方法 (ドラッグ＆ドロップ)**:
  - WebUIの左ペイン「Live2Dモデルが未配置です」領域に、ダウンロードした公式推奨モデル（銀髪モデル `ulvm2_0001` / 茶髪モデル `fav_usaneko_alwb`）のZIPファイルをそのままドラッグ＆ドロップします。
  - 二重ZIPやフォルダ階層が自動解析・展開され、即座に適用されます。
  - ※公式2モデル以外の任意Live2Dモデルの自動読込は現行未サポートです。独自アバターを追加する場合は VRM 3D 形式をご利用ください。
- **手動配置先**:
  - 銀髪モデル: `llama-b9873-bin-win-cuda-13.3-x64sandbox/custom_public/deining/ulvm2_0001/`
  - 茶髪モデル: `llama-b9873-bin-win-cuda-13.3-x64sandbox/custom_public/deining/fav_usaneko_alwb/`
  - ※ダウンロードしたZIPを展開し、`.model3.json` やテクスチャフォルダを上記ディレクトリへ配置してください。フォルダ名を「銀髪の女の子」「茶髪の癒し系お姉さん」とした場合も自動認識されます。

### 7.2 VRM 3D モデルの配置
- **インポート方法**:
  - WebUIのモデル選択パネルから `.vrm` ファイルをアップロード（またはドラッグ＆ドロップ）します。
  - バックエンドでメタデータが抽出され、`custom_public/deining/vrm/<model_id>/` 配下に配置されます。
- **ライセンスの確認**:
  - VRM ファイルに設定されている利用規約（商用利用、再配布条件など）を事前にご確認の上でご利用ください。

### 7.3 TTS モデルの配置
- **使用モデル**:
  - **24GB (Ultra) 環境**: `Aratako/Irodori-TTS-v4-Small` (BF16, 約3.0GB)
  - **16GB以下 (8GB〜16GB) 環境**: `Aratako/Irodori-TTS-v4-Small-Quantized` (float8 weight-only, 約873MB)
- **配置先**: `backend/Irodori-TTS/models/model.safetensors`
- **ダウンロード元**:
  - 24GB: [Hugging Face: Aratako/Irodori-TTS-v4-Small](https://huggingface.co/Aratako/Irodori-TTS-v4-Small)
  - 16GB以下: [Hugging Face: Aratako/Irodori-TTS-v4-Small-Quantized](https://huggingface.co/Aratako/Irodori-TTS-v4-Small-Quantized)
- ※インストーラー（`install.bat`）実行時にVRAM容量に応じて自動取得されます（手動配置も可能）。
