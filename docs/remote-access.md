# セキュア・リモートアクセス仕様書 (LAN / Tailscale Remote Access)

本書は、泥濘 (Deinei) システムにおける外部端末（スマートフォン・タブレット・外出先PC等）連携、認証ゲートウェイ（ポート 8090）、同一LAN内通信、および Tailscale WireGuard メッシュ通信に関する技術仕様を定義したドキュメントです。

---

## 1. 設計方針とセキュリティ原則

泥濘は「通信が自己の管理下で完結する」原則に従い、クラウドベンダーや第三者の中継サーバー（Cloudflare Tunnel, ngrok 等）は使用しません。

- **バックエンドのローカル隔離**:
  - LLM推論（8080）、Flask/RAG（5000）、TTS（5001）は常に `127.0.0.1`（ローカルループバック）にのみバインドされ、外部ネットワークに露出することはありません。
- **独立認証ゲートウェイ（ポート 8090 / 自動スライド）**:
  - 外部アクセス用として単一の認証リバースプロキシ（`gateway.py`）のみを開放します。
  - ポート 8090 が他アプリで使用中の場合、ポート 8090〜8109 の範囲で空きポートを自動探索・スライドして起動するフェイルセーフ機構を備えています。
- **暗号学的トークン認証**:
  - 起動毎に暗号学的乱数で生成されたトークンを使用し、定数時間照合（`hmac.compare_digest`）でタイミング攻撃を防止します。
  - 初回アクセス成功時に `HttpOnly` / `SameSite=Lax` Cookie を発行し、ブラウザのURLバーからトークン文字列を自動除去します。

## 2. 接続方式

### 2.1 LAN モード (同一Wi-Fi)
- **バインド**: `0.0.0.0:8090`
- **対象**: 自宅やオフィスの同一Wi-Fiルーターに接続された端末。
- **URL形式**: `http://<LAN_IP>:8090/?token=<TOKEN>`

### 2.2 Tailscale モード (外出先・モバイル回線)
- **バインド**: Tailscale 仮想インターフェースのIP（`100.x.x.x:8090`）でのみ待受（`0.0.0.0` にはバインドしません）。
- **対象**: Tailscale の暗号化メッシュ（WireGuard ベース）に参加している自己所有端末。
- **特徴**: ルーターのポート開放（NAT越え）を行うことなく、外出先スマホの4G/5G回線から安全に直接P2P通信が可能です。
- **URL形式**: `http://<Tailscale_IP>:8090/?token=<TOKEN>`

## 3. 利用手順

### 3.1 統合ランチャーからの操作 (推奨)
1. `start_ai_servers.bat` を起動し、統合ランチャー画面を開きます。
2. 画面上部の公開モードセレクターから **「LAN 公開」** または **「Tailscale 公開」** を選択します。
3. **「QRコード表示」** ボタンを押すと、接続用QRコードおよびURLが表示されます。
4. スマートフォンのカメラアプリ等でQRコードを読み取ることで、対話画面（Web UI）に接続されます。

### 3.2 Tailscale リモート連携アシスタント
ランチャー画面で「Tailscale 公開」を選択した際、未導入または未認証の場合は内蔵アシスタントが立ち上がります：
- **未インストール時**: 「Tailscale をインストール (UAC)」ボタンから公式インストーラーをダウンロード・実行可能。
- **未認証時**: 「ブラウザでログイン画面を開く」ボタンから Tailscale の認証ページを呼び出し。
- **接続完了検知**: バックグラウンドポーリングで接続状態を自動検知し、準備完了時にURL・QRコードを発行します。
- **MagicDNS 連携**: Tailscale のドメイン管理（MagicDNS）が有効な場合、マシン名ベースのURL（例: `http://<machine-name>.<tailnet>.ts.net:8090/`）が利用可能です（通信はTailscaleのWireGuardメッシュによりエンドツーエンドで暗号化されます）。

### 3.3 コマンドライン・補助起動バッチ群 (`scripts/`)
GUIランチャーを経由せず、直接特定モードで起動したい上級者向けに以下のバッチファイルを用意しています：
- `scripts/start_ai_servers_lan.bat`: LAN 公開モードで即時起動
- `scripts/start_ai_servers_tailscale.bat`: Tailscale 専用公開モードで即時起動
- `scripts/deinei_doctor.bat`: ネットワーク診断スクリプトを単体実行

## 4. トラブルシューティング ＆ 接続診断

### 4.1 Doctor 接続診断
ランチャー上部の「Doctor 接続診断」ボタン（または `scripts/deinei_doctor.bat`）を実行すると、以下の項目が自動診断されます：
- 各サーバー（8080, 5000, 5001, 8090）のポート待受状態およびヘルスチェック応答
- LAN IP アドレス候補の検出
- Windows ネットワークプロファイル（Private / Public）の確認
- Tailscale デーモンの稼働状態（Running / NeedsLogin / NotInstalled 等）

### 4.2 Windows Defender ファイアウォールによる遮断対策
同一Wi-Fiのスマホから接続できない場合、Windows の接続プロファイルが「パブリック（Public）」になっていることが原因の多くを占めます。
自宅や安全なWi-Fi環境の場合、管理者権限の PowerShell で以下を実行して「プライベート（Private）」に設定してください：

```powershell
Set-NetConnectionProfile -InterfaceAlias 'Wi-Fi' -NetworkCategory Private
```
